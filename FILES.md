# Файлы сессии

У каждой беседы отдельная рабочая папка:
`sessions/<chat_id>/workspaces/<engine>/<workspace_id>/`.
Идентификатор рабочей папки постоянен, в том числе когда Codex выдаёт ID треда
после первого запроса. Токены и служебное состояние находятся вне рабочей папки.

```
files/
  from_user/  новые вложения пользователя
  for_user/   готовые файлы ИИ для отправки
  general/    архив обеих сторон
MEMORY.md     постоянная память сессии
AGENTS.md     правила работы с файлами
CLAUDE.md     те же правила для Claude
```

Фото, видео, документы, анимации, видеосообщения и стикеры
скачиваются в `from_user`. Вложения и альбомы без текстовой подписи или аудио
только сохраняются: бот не вызывает модель и не переносит их в архив.
Следующий текст, подпись, голосовое или аудиосообщение запускает обработку
накопленных файлов. Альбом с контекстом обрабатывается одним запросом.
Фото по-прежнему передаются модели как изображения.
Голосовые и аудиосообщения скачиваются только в память и расшифровываются:
модель получает текст, исходное аудио не сохраняется в папках сессии.
При ошибке распознавания или пустой расшифровке бот сообщает об этом;
без другого текста модель не вызывается, накопленные файлы остаются в очереди.

Системные инструкции и напоминание в каждом запросе требуют проверить
`files/from_user` и память. После успешного ответа входящие файлы перемещаются
в `general`. При ошибке модели остаются в `from_user`. Обычные файлы из `for_user`,
включая вложенные каталоги, отправляются документами и переносятся в `general`
только после подтверждения Telegram. Неотправленные файлы остаются для повтора
после следующего успешного ответа. Совпадающие имена получают уникальный суффикс.
Ссылки, hardlink и специальные файлы не отправляются.

`/new` создаёт отдельную рабочую папку; `/sessions` возвращает прежние файлы.
Подтверждённый `/delete` удаляет историю и файлы выбранной беседы.
Переключение сессии ожидает завершения текущей обработки и отправки файлов.

## Права и зависимости

Claude запускается с ограниченными файловыми инструментами и песочницей Bash
(`--restricted`, `sandbox.enabled`, `failIfUnavailable`, запрет выполнения
команд вне песочницы). Для Linux нужны `bubblewrap` и `socat` в PATH.
Codex получает `workspace-write`, рабочую папку через родительский `exec -C`
и запрет запросов расширенных прав. Эти параметры передаются и при resume,
переопределяя старый read-only конфиг. TG_* не передаются процессам моделей.

Требуются версии CLI с указанными флагами; проверено на сервере с
Claude Code 2.1.272 и codex-cli 0.154.0.

Ограничения облачного Telegram Bot API: скачивание до 20 МБ, отправка до 50 МБ.
Поддержка сохранения формата не означает, что модель сможет разобрать его
содержимое без подходящих инструментов. Пустые и слишком большие исходящие
файлы сохраняются с сообщением об ошибке отправки.
