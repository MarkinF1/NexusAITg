# NexusAI

Telegram-бот, который превращает ваш компьютер или сервер в личного ИИ-ассистента.
Внутри работают **Claude Code** и (по желанию) **Codex** по **вашей подписке**:
API-ключи и оплата за токены не нужны.

## Зачем он нужен

- **Claude и Codex в телефоне.** Пишете боту как в обычный чат, а отвечает
  полноценный агент, который умеет читать и создавать файлы, запускать команды
  и ходить в интернет.
- **Работа с файлами.** Присылаете документ, таблицу, архив или фото и просите
  разобрать, исправить или сконвертировать. Готовые файлы бот присылает обратно.
- **Голосовые сообщения.** Надиктовали задачу, бот расшифровал её локально
  (faster-whisper) и передал модели как текст.
- **Долгие беседы.** Контекст и файлы сохраняются на диске, поэтому можно
  продолжить завтра с того же места или вернуться к прошлой сессии.
- **Общая память.** Важное (как вас зовут, ваши предпочтения) бот помнит во
  всех сессиях вашего чата, а в группе — во всех темах этой группы.
- **Командная работа в группе.** В группе с темами каждая тема — отдельная
  сессия со своей моделью, историей и файлами.
- **Одна подписка на нескольких человек.** Вы решаете, кому из пользователей
  Telegram разрешён доступ.

## Как пользоваться

### Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и список возможностей; в группе — подключение группы |
| `/info` | Текущая модель, сессия и число сообщений |
| `/model` | Выбор движка (Claude/Codex) и модели |
| `/effort` | Уровень размышления: от быстрого ответа до глубокого анализа |
| `/new` | Новая сессия с чистым контекстом; в группе `/new Название` создаёт тему |
| `/sessions` | Список прошлых сессий (или тем группы) с переходом к ним |
| `/delete` | Удаление сессии вместе с её файлами (с подтверждением) |

### Личный чат

Просто пишите. Каждое сообщение продолжает текущую сессию. `/new` начинает с
чистого листа, а старые сессии остаются в `/sessions`.

Модели Claude: `opus` (сложные задачи, архитектура), `sonnet` (повседневная
работа, по умолчанию), `haiku` (быстрые и простые вопросы). Список моделей
Codex бот берёт из самого `codex`.

### Файлы, фото и голосовые

- **Фото** передаются модели как изображения. Альбом уходит одним запросом.
- **Документы, видео, стикеры** сохраняются в рабочую папку сессии.
- **Вложение без подписи** только сохраняется, модель не вызывается. Можно
  прислать несколько файлов, а потом одним сообщением сказать, что с ними
  сделать.
- **Голосовые и аудио** расшифровываются в памяти, оригинал не сохраняется.
- **Готовые файлы** модель кладёт в специальную папку, и бот присылает их
  документами.
- Ограничения Telegram: бот скачивает файлы до 20 МБ, отправляет до 50 МБ.

Как устроена рабочая папка, описано в [FILES.md](FILES.md).

### Группы с темами

1. Включите темы в группе и добавьте туда бота администратором (для `/new`
   нужно право «Управление темами»).
2. Разрешённый пользователь отправляет `/start` в группе.
3. Создайте тему (вручную или командой `/new Название`) и выберите модель.

Одна тема — одна сессия. Все допущенные участники темы видят общую историю и
файлы. Подробности в [TOPICS.md](TOPICS.md).

### Права

- **Администраторы** (`TG_ALLOWED`) имеют доступ ко всему: могут менять
  модель и удалять сессии в любой теме, им доступны модели только для админов.
- **Пользователи** (`TG_USERS`) пользуются ботом; в группах управляют только
  темами, которые создали сами.
- Остальным бот не отвечает.

## Установка

Бот работает на **Linux с systemd** (проверено на Debian). На Windows его можно
запустить через WSL2. Компьютер должен быть включён: пока он выключен, бот не
отвечает.

### 1. Системные пакеты

```sh
sudo apt install git python3 python3-venv bubblewrap socat
```

`bubblewrap` и `socat` нужны песочнице, в которой Claude выполняет команды. Без
них бот откажется запускать команды модели.

### 2. Claude Code (и по желанию Codex)

Установите Claude Code и войдите в аккаунт с подпиской под тем пользователем,
от которого будет работать бот:

```sh
curl -fsSL https://claude.ai/install.sh | bash
claude auth login
```

Codex необязателен. Если он установлен и авторизован (`codex login`), в
`/model` появятся его модели.

### 3. Бот в Telegram

1. Напишите [@BotFather](https://t.me/BotFather) и выполните `/newbot`, чтобы
   получить токен.
2. Узнайте свой Telegram ID, например, у [@userinfobot](https://t.me/userinfobot).

### 4. Установка бота

Бот ставится в `/opt/NexusAI`: на этот путь рассчитан systemd-сервис.

```sh
sudo git clone https://github.com/MarkinF1/NexusAI.git /opt/NexusAI
sudo chown -R "$USER": /opt/NexusAI
cd /opt/NexusAI
cp .env.example .env && chmod 600 .env
nano .env        # впишите TG_TOKEN и TG_ALLOWED
./start.sh
```

`start.sh` создаёт виртуальное окружение, ставит зависимости, заранее скачивает
модель распознавания речи (~0.5 ГБ) и запускает пользовательский
systemd-сервис `claude-tg`, который поднимается сам после перезагрузки.

Откройте бота в Telegram и отправьте `/start`.

### Управление

```sh
journalctl --user -u claude-tg -f        # логи
systemctl --user restart claude-tg       # перезапуск (например, после правки .env)
systemctl --user stop claude-tg          # остановка
cd /opt/NexusAI && git pull && systemctl --user restart claude-tg   # обновление
```

## Настройка

Все параметры задаются в `.env`, пример с комментариями лежит в
[.env.example](.env.example).

| Переменная | Назначение |
|---|---|
| `TG_TOKEN` | Токен бота от @BotFather (обязательно) |
| `TG_ALLOWED` | ID администраторов через запятую (обязательно) |
| `TG_USERS` | ID обычных пользователей |
| `TG_GROUPS` | ID групп, подключённых заранее |
| `CLAUDE_TG_ENGINE` | Движок по умолчанию: `claude` или `codex` |
| `CLAUDE_TG_MODEL` | Модель Claude по умолчанию: `opus`, `sonnet`, `haiku` |
| `CLAUDE_TG_STT_MODEL` | Модель распознавания речи: `tiny` … `large-v3` |
| `CLAUDE_TG_STT_LANG` | Язык голосовых (`ru`, `en`); пусто — автоопределение |
| `CLAUDE_BIN`, `CODEX_BIN` | Пути к CLI, если их нет в `PATH` |
| `CLAUDE_TG_SESSIONS` | Где хранить сессии (по умолчанию `sessions/` рядом с ботом) |

## Безопасность

- Каждый допущенный пользователь работает от вашей подписки и может просить
  модель выполнять команды на вашем компьютере. Давайте доступ только тем,
  кому доверяете.
- Claude и Codex работают в песочнице: им доступна только папка данных
  текущего чата или группы. Домашний каталог, папка бота (с `.env`), токены
  подписок и другие чаты закрыты. Токен Telegram процессам моделей не передаётся.

## Проблемы

- **«не найден исполняемый claude»**: укажите путь в `CLAUDE_BIN` в `.env`.
- **Команды модели не выполняются, ошибки песочницы**: проверьте, что работает
  `bwrap --ro-bind / / true`. Если нет, значит, система запрещает
  непривилегированные user namespaces.
- **Бот молчит в группе**: сделайте его администратором группы или отключите
  Privacy Mode в @BotFather и добавьте бота в группу заново.
