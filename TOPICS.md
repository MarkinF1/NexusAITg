# Темы Telegram

## Подключение

1. Включите темы в группе Telegram и добавьте бота.
2. Для обычного общения без упоминаний назначьте бота администратором.
   Для команды `/new` ему нужно право **Управление темами**.
   Альтернатива для ручного создания тем: отключить Privacy Mode через BotFather
   и заново добавить бота в группу.
3. Любой разрешённый пользователь (из `TG_ALLOWED` или `TG_USERS`) отправляет
   `/start` в группе. Подключение сохраняется после перезапуска. Также можно
   задать `TG_GROUPS` списком ID групп через пробел или запятую.
4. Создайте тему вручную или отправьте `/new Название` и выберите модель.

Бот отвечает пользователям из существующих `TG_ALLOWED` и `TG_USERS`.
Все допущенные участники одной темы пользуются общей историей и файлами.
Модель, размышление и удаление сессии доступны создателю темы и администраторам
бота. Если событие создания темы пропущено или тема создана анонимно,
первую модель выбирает администратор бота; он становится владельцем сессии.

## Поведение

- Одна тема — одна сессия. Первый выбор модели закрепляет движок Claude/Codex.
- `/model` меняет модель внутри закреплённого движка, сохраняя историю и файлы.
  Доступ к Astra по-прежнему ограничен администраторами бота.
- `/effort` и `/info` относятся к текущей теме.
- `/new Название` создаёт новую тему; текущая сессия сохраняется.
- `/sessions` показывает известные боту темы с кнопками перехода.
- Закрытие/открытие и переименование темы сохраняют её сессию.
- `/delete` с подтверждением удаляет историю ИИ и рабочие файлы текущей темы.
  Тема и сообщения Telegram остаются; для новой сессии создайте новую тему.
- При удалении темы через интерфейс Telegram бот автоматически не стирает
  локальную историю: отдельного события удаления темы Bot API не предоставляет.
- Если бот не видел создание, настройка появляется при первом сообщении.
  Вопрос, отправленный до выбора модели, нужно повторить после выбора.
  Прикреплённые файлы сохраняются и доступны выбранному движку.
- Общая тема (General) имеет собственную сессию, отдельную от других тем.

Вложения без подписи сохраняются в `from_user` и не вызывают ИИ.
Голосовые/аудио расшифровываются в памяти без сохранения оригиналов.
Текст или расшифровка запускают обработку накопленных файлов темы.
Ответы, документы и индикатор набора отправляются в исходную тему.

## Хранение и совместимость

Ключ беседы — `(chat_id, message_thread_id)`, для General используется `1`.

```
sessions/<group_id>/
  forum.json                 подключение группы
  topics/<thread_id>/
    topic.json               имя, владелец, движок, закрытие/удаление
    active / active-codex    ID сессии выбранного движка
    model / model-codex      модель
    ...                     служебное состояние Claude/Codex
  data/                      всё, что доступно модели
    MEMORY.md                общая память всех тем группы
    topics/<thread_id>/
      MEMORY.md              память темы
      files/from_user/
      files/for_user/
      files/general/
```

Метаданные находятся вне доступной модели папки `data/`. Для каждой темы
используется своя блокировка запросов и свой буфер альбомов. Смена настроек
во время ответа отклоняется с просьбой повторить её после завершения.

Личные чаты используют прежние пути и команды. Старую общую историю группы,
созданную до поддержки тем, бот сохраняет по прежнему пути; автоматически
распределить её между темами нельзя.

Проверки:

```
.venv/bin/python test_bot.py
.venv/bin/python -m unittest -q test_files
.venv/bin/python -m unittest -q test_topics
```

Тесты тем проходят через Dispatcher aiogram с подменой транспорта Telegram;
они не отправляют сообщения в реальные группы.

Документация: [Bot API](https://core.telegram.org/bots/api#forumtopiccreated),
[Privacy Mode](https://core.telegram.org/bots/features#privacy-mode),
[ссылки на темы](https://core.telegram.org/api/links#forum-topic-links).
